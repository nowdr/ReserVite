# Restaurant Reservation App

Application de gestion de réservations de restaurants.

Projet réalisé dans un cadre académique.

## Fonctionnalités principales

* **Authentification et Gestion :** Inscription, connexion, déconnexion.
* **Espace Client :**

  * Recherche et consultation des restaurants disponibles.
  * Ajout, modification, consultation et annulation des réservations.
* **Espace Manager :**

  * Gestion des restaurants et suivi des réservations.
  * Confirmation des réservations avec attribution des tables, annulation et clôture.

## Gestion de l'état

* Utilisation de Riverpod pour la gestion de l'état global et la cohérence des données.

## Stack technique

* Frontend : Dart, Flutter (Riverpod)
* Backend / Données : PostgreSQL, PostgREST
* Gestion de version : Git
